# Model Finder branding

The mark represents candidate paths converging on a selected model. Cyan, blue, and violet ribbons surround a mint selection point. The README banner pairs the mark with the Model Finder wordmark on a dark technical grid.

- [Transparent logo](../assets/brand/model-finder-logo.webp): square WebP for repository artwork and other compact uses.
- [README banner](../assets/brand/model-finder-banner.webp): wide WebP with the wordmark and tagline, designed to stay legible in both GitHub themes.

Both original assets were created with the built-in image generation tool. The repository license applies to the included assets. No upstream provider logos are included.

For the 2026-11-01 launch preparation, the banner was resized to 1280 ? 533 and the transparent logo to 640 ? 640, then encoded as WebP (quality 88). Both are well below 200 KB. The original design and logo transparency are preserved; generation prompts below document their origin.

The badge versions describe the source package; they do not imply a published GitHub release or a successful hosted CI run. Once the repository has a public remote, a live workflow badge can point at its actual workflow URL.

## Generation prompts

Logo, generated with a transparent background:

```text
Use case: logo-brand.
Asset type: original repository logo for an open-source developer tool named Model Finder.
Create one exceptionally clean, distinctive, compact geometric symbol, no words. Concept: three precise angular candidate paths converge into one selected diamond/checkpoint, subtly suggesting an M and an F through negative space. A thoughtful selection/finder symbol, balanced and recognizable at small sizes. Rounded angular ribbons, restrained polished vector-like finish, strong silhouette, confident spacing, front-on flat view. Palette: vivid electric cyan transitioning through blue to violet, small mint highlight at the selected central node. Crisp opaque geometry with subtle controlled dimensional shading; keep the negative spaces open. Centered square composition, symbol occupies about 78% of square. Genuine transparent background, no backdrop, no presentation board, no shadow outside mark. Original identity; no existing company logos, no infinity symbol, no robot, no brain, no magnifying-glass cliché. No text, no watermark. Intended for a GitHub README and square repository avatar.
```

Banner, generated using the logo as its reference image:

```text
Use case: logo-brand.
Asset type: finished wide GitHub README hero banner, approximately 1536 by 640 pixels, landscape.
Reference image 1 is the newly designed Model Finder logo. Preserve that exact distinctive cyan-to-blue-to-violet ribbon mark with mint selected diamond; integrate it as the brand symbol, do not invent a different icon.
Make a premium open-source developer-tool brand header. Deep midnight navy (#0b1020) backdrop, an extremely subtle technical grid and very restrained cyan/violet ambient light, spacious and meticulously aligned. Clean horizontal lockup: the reference mark on the left at a tasteful size, on the right a very large sharp white geometric sans-serif wordmark on two lines reading exactly "MODEL" then "FINDER". Beneath the wordmark a single small letterspaced light cyan line reading exactly "LIVE PRICES. INDEPENDENT EVIDENCE."
The brand mark and typography should form one balanced compact group centered with generous margins. Strong readable typography, deliberate typographic hierarchy, smooth clean edges, restrained flat/vector-like brand design. Minimal sophistication. Dark background must be uniform enough to look good in GitHub light and dark themes. No mockup, no screenshot frame, no shiny chrome, no photoreal objects, no badges, no invented feature claims, no extra text, no watermark.
```
