# Model Finder branding

The README banner shows five connected glass tiles, with one highlighted in mint and cyan to represent a selected model. It contains no letters, numbers, monograms or captions. The separate transparent logo is the original cyan, blue and violet geometric mark.

- [Transparent logo](../assets/brand/model-finder-logo.webp): square WebP for repository artwork and other compact uses.
- [README banner](../assets/brand/model-finder-banner.webp): wide, text-free WebP illustration with one selected tile.

Both assets were created with the built-in image generation tool. The banner was replaced on 2026-11-01 with a new text-free image. The repository license applies to the included assets. No upstream provider logos are included.

The current banner is 1280 x 427 pixels and approximately 12 KB. The transparent logo is 640 x 640 and approximately 46 KB. Both use WebP quality 88 and stay below 200 KB. Resizing and encoding preserve the generated artwork; the original generated file remains outside the repository. The logo retains its alpha channel.

The badge versions describe the source package; they do not imply a published GitHub release or a successful hosted CI run. Once the repository has a public remote, a live workflow badge can point at its actual workflow URL.

```text
Create one exceptionally clean, distinctive, compact geometric symbol, no words. Concept: three precise angular candidate paths converge into one selected diamond/checkpoint, subtly suggesting an M and an F through negative space. A thoughtful selection/finder symbol, balanced and recognizable at small sizes. Rounded angular ribbons, restrained polished vector-like finish, strong silhouette, confident spacing, front-on flat view. Palette: vivid electric cyan transitioning through blue to violet, small mint highlight at the selected central node. Crisp opaque geometry with subtle controlled dimensional shading; keep the negative spaces open. Centered square composition, symbol occupies about 78% of square. Genuine transparent background, no backdrop, no presentation board, no shadow outside mark. Original identity; no existing company logos, no infinity symbol, no robot, no brain, no magnifying-glass cliché. No text, no watermark. Intended for a GitHub README and square repository avatar.
```
