# Model Finder v0.1.0

Model Finder helps Claude Code, Codex and OpenCode choose AI models using live OpenRouter prices, capabilities, provider routes and independent benchmark evidence.

- Guided npx installation with explicit project/global scope, preserved settings and pending OAuth reporting.
- Portable `model-finder` skill plus Claude and Codex plugin manifests.
- Account-free, GET-only Python catalog helper and reproducible cost calculations.
- Explicit model identity mapping, unknown benchmark values and provisional recommendations when task evidence is missing.
- Dated price-only demonstration, clean-room install verification and compressed brand assets.

Install:

```bash
npx --yes github:Saad-Hassan25/model-finder
```

Node.js 22+ and Git are required. Source authentication is separate from successful file installation. Model Finder does not run paid inference or automatically switch its host agent's model. See README.md and INSTALL.md in the release for setup, and docs/release.md for the exact verification boundaries.
